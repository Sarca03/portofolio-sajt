# 💻 Bogdan OS — Retro Portfolio

Unikatni portfolio izrađen u formi retro operativnog sistema, koji spaja strast prema grafičkom dizajnu, modernom frontend/backend programiranju i retro gejming/hakerskoj estetici.

## 🚀 Karakteristike projekta
- **Retro OS Desktop Okruženje:** Interaktivne ikonice i prozori inspirisani retro operativnim sistemima.
- **Draggable Windows:** Mogućnost pomeranja otvorenih prozora mišem po ekranu.
- **Web Audio API Zvučni Efekti:** Sintetički retro zvučni tonovi ugrađeni direktno u kod (bez spoljnih audio fajlova).
- **Dvojezičnost (SR / EN):** Trenutno prevođenje celog sajta sa srpskog na engleski jezik jednim klikom.
- **Interaktivni Terminal:** Podrška za komande (`help`, `about`, `skills`, `projects`, `contact`, `clear`).
- **Scanlines Visuals:** Autentičan efekat starog monitora preko Tailwind CSS-a.

## 🛠️ Korišćene Tehnologije
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS
- **Dizajn & Koncept:** Figma, UI/UX Principles
- **Alati:** Git, GitHub, VS Code

## 📦 Pokretanje projekta
1. Kloniraj repozitorijum ili preuzmi fajlove.
2. Otvori `index.html` u svom pretraživaču ili pokreni preko *Live Server* ekstenzije u VS Code-u.
